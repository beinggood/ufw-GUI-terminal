ufw-gui-terminal

一个基于 dialog 的 UFW 防火墙终端图形化配置工具。  
支持鼠标点击操作，适合在 SSH 终端、服务器维护、批量配置防火墙规则时使用。

功能

查看防火墙状态
启用 / 禁用防火墙
设置默认入站策略
添加放行规则
添加服务预设规则
添加拒绝规则
查看已有规则列表
删除规则
备份规则
恢复规则
查看本次会话命令日志
重置防火墙

界面预览

运行后会进入终端图形菜单：

 UFW 防火墙图形化配置工具

请选择操作（支持鼠标点击）：

 1  查看防火墙状态
 2  启用 / 禁用防火墙
 3  设置默认策略
 4  添加放行规则（端口）
 5  添加服务预设规则
 6  添加拒绝规则
 7  查看已有规则列表
 8  删除规则
 9  备份规则
10  恢复规则
11  查看命令日志
12  重置防火墙
 0  退出

环境要求

Linux 系统
bash
ufw
dialog
root 权限

安装依赖

Debian / Ubuntu：

sudo apt update
sudo apt install ufw dialog

Fedora / RHEL / CentOS Stream：

sudo dnf install ufw dialog

使用方法

下载脚本后，赋予执行权限并运行：

chmod +x ufw-gui.sh
sudo bash ufw-gui.sh

也可以直接运行：

sudo bash ufw-gui.sh

功能说明
功能   说明
查看防火墙状态   显示 ufw status verbose 结果

启用 / 禁用防火墙   执行 ufw enable 或 ufw disable

设置默认策略   设置入站流量默认策略

添加放行规则   支持 TCP、UDP、TCP+UDP，可指定来源 IP

添加服务预设规则   快速放行 SSH、HTTP、HTTPS、MySQL 等常用服务

添加拒绝规则   对指定端口添加拒绝规则

查看规则列表   显示带编号的当前规则

删除规则   根据规则编号删除指定规则

备份规则   将当前规则导出到文件

恢复规则   从备份文件中解析并恢复规则

查看命令日志   查看本次会话中执行过的命令

重置防火墙   执行 ufw reset，清除所有规则

交互说明

在功能菜单中点击 取消，会返回主菜单。
在主菜单中点击 取消 或选择 退出，会退出程序。
执行危险操作前会弹出确认框。
本次会话执行的命令会记录到临时日志文件中。

注意事项

此工具需要 root 权限运行。
修改防火墙规则可能影响 SSH 远程连接，请谨慎操作。
建议在操作前备份当前规则。
重置防火墙会清除所有已有规则。
恢复规则功能依赖备份文件格式，建议优先使用本工具导出的备份文件。
